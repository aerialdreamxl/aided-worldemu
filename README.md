# The WEMU Project (Core)

> `WEMU` means `WEMU EMulate the Universe`

> This repo contains **The core library package of WEMU**

**Warning: This project is currently pre-alpha, anything is not guranteed**

## What is this 🤔
WEMU is a project which use LLM Agents to simulate simple human actions, aims to solve some history curious problems, screenwriting and so on.

## What's the progress 📈
- [X] Basic Data Structure

- [ ] First world running (Hongloumeng running test)

## Choosing model for WEMU
I suggest using **Self-hosted Latest SOTA Opensource LLM Possible** for both privacy and demonitering

This project is optimized for **Qwen Series** when it was written,so [Qwen Models](https://huggingface.co/Qwen) are recommended

## How to install?
Simply git clone this repo and `pip install .`
